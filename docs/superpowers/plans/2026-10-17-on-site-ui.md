# LibSaver: кнопка на сайте, окно поверх страницы, фоновая очередь, Firefox — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Скачивание LibSaver прямо со страницы тайтла: кнопка «Скачать» + ⚙ под «Начать читать», окно поверх сайта с меню слева, загрузка в фоне с очередью и прогрессом на странице; работает в Chrome и Firefox (ПК и Android).

**Architecture:** Движок загрузки (`download.js` + `formatters/*` + `api.js`) переезжает из окна «Подготовка» в фоновый документ: в Chrome — offscreen-документ, в Firefox — фоновая страница. Всё, что нужно делать в странице сайта (`chrome.scripting.executeScript`), собрано в один файл функций и выполняется на любой открытой вкладке нужного сайта. Интерфейс на сайте рисует content script (кнопки, плашка — Shadow DOM), а окно и быстрое окошко — это iframe со страницами расширения; с движком они общаются через `runtime.connect`-порт.

**Tech Stack:** Chrome MV3 / Firefox WebExtensions, обычный JS без сборщика (глобальные скрипты, подключаемые из HTML), `node:test` + `vm` для тестов, Font Awesome, Inter, jszip, pica, pdf-lib.

**Spec:** `docs/superpowers/specs/2026-10-17-on-site-ui-design.md` (+ макеты в `docs/superpowers/specs/2026-10-17-on-site-ui-mockups/`).

## Review Focus

1. **Вкладка исчезла посреди загрузки манги** (закрыли, ушли на другой LIB-сайт, перезагрузили): загрузка переходит на другую вкладку того же сайта или встаёт на паузу с подсказкой, и сама продолжается, когда вкладка появилась; чужой сайт не используется. → тесты в Task 1 (`findSiteTab`) и Task 4 (`waiting-tab`).
2. **SPA-переходы по сайту**: после перехода «тайтл → тайтл → каталог → тайтл» без перезагрузки кнопок ровно одна пара на странице тайтла и ноль вне её. → тест в Task 7 (`ensureButtons` идемпотентна).
3. **Ошибка главы/картинки в фоне, когда окно закрыто**: загрузка ждёт решения «Повторить/Пропустить», плашка говорит «нужно решение», клик открывает раздел загрузки с кнопками. → тест в Task 3 (событие `decision`) и Task 9 (текст плашки).
4. **Второй «Скачать» того же тайтла, пока он в очереди или качается**: не создаёт дубль; пользователь видит, что тайтл уже в очереди. → тест в Task 4 (`enqueue` отклоняет дубль по `slug` среди `queued|running|paused|waiting-*`).
5. **Сообщения от чужих страниц**: content script и iframe принимают `postMessage` только от своего iframe/родителя с правильным origin; страница сайта не может закрыть окно или запустить загрузку. → тест в Task 7 (`isTrustedFrameMessage`).

- Порт: `chrome.runtime.connect({ name: 'libsaver-engine' })`.

  - Движок → клиент: `{ type: 'state', state }` (при подключении и при каждом изменении, не чаще раза в 250 мс), `{ type: 'log', id, line, isError, color }`, `{ type: 'enqueueResult', ok, reason? }`.
- `state = { items: QueueItem[], stats: Stats | null, logTail: LogLine[] }`, где
  `QueueItem = { id, slug, siteKey, title, format, status, progress: { current, total }, error?, decision?, filename? }`,
  `status ∈ 'queued' | 'running' | 'paused' | 'waiting-tab' | 'waiting-decision' | 'done' | 'error' | 'canceled'`,
  `decision = { kind: 'chapter' | 'image', chapterTitle, message, imageUrl? }`,

- `runtime.sendMessage` в фон (SW в Chrome / фоновая страница в Firefox): `{ action: 'pageCall:findTab', siteKey, preferredTabId }` → `number | null`; `{ action: 'pageCall:exec', tabId, name, args }` → `{ ok: true, result } | { ok: false, error, tabGone }`; `{ action: 'ensureEngine' }` → `true`; `{ action: 'saveFile', url, filename }` → `{ ok, error? }`; `{ action: 'whoami' }` → `{ tabId, url }` (из `sender.tab`); `{ action: 'openPanel', section? }` от popup → пересылается `chrome.tabs.sendMessage(tabId, { action: 'libsaver:openPanel', section })`.
- `postMessage` iframe ↔ content script: `{ libsaver: true, type: 'close' | 'resize' | 'openPanel', height?, section? }`.

Если в контексте нет `chrome.scripting`/`chrome.tabs` (offscreen в Chrome), `findSiteTab`/`execPageCall` выполняются через `runtime.sendMessage` `pageCall:findTab` / `pageCall:exec`.
  - `setNoTabHandler(fn: (siteKey) => Promise<void>)`.
- Consumes: `getSiteConfig(url)` из `api.js` — перенести её в `page-call.js` (она нужна SW, а `api.js` в SW не грузится) и оставить в `api.js` вызов этой же функции.
